# BizPilot First-Sale Offer

## Recommended starting offer

**BizPilot Commercial — $149 one-time**

This is the first package to test. Keep the offer simple and sell the current `0.1.0` codebase as a ready-to-customize starting point.

### Buyer receives

- Full BizPilot source code
- Next.js frontend
- FastAPI backend
- Supabase/PostgreSQL migrations
- Supabase Auth integration
- Multi-organization workspace model
- Role-aware access control
- Customer, product, service, invoice, payment, expense, and report modules
- Invoice PDF generation
- CI configuration
- Setup and deployment documentation
- Buyer/demo documentation

### License boundary

The buyer receives a commercial use license for one application/project. The buyer does not automatically receive the right to redistribute BizPilot itself, resell the source code, sublicense the source code, or publish the code as a competing template.

The actual legal license should be supplied as a separate written agreement before payment. This document is a product-packaging plan, not legal advice.

## Higher-value package

**Agency / White-label — $399+**

Use this only when a buyer specifically needs client deployments, broader customization rights, or white-label permission. Price and rights should be agreed separately.

## What we should not promise

Do not promise guaranteed revenue, production support without limits, tax/accounting compliance for every country, unlimited custom features, or ownership of third-party services.

## Sales sequence

1. Send the public demo.
2. Show the 90-second workflow from customer to invoice to payment.
3. Explain that the buyer is purchasing saved development time and a working foundation.
4. Give the buyer the README and deployment guide before checkout.
5. Deliver the exact release version purchased.
6. Keep custom development separate from the source-code license.

## Minimum proof to collect before increasing the price

Get at least one successful buyer installation and one real customization request. Use that feedback to improve documentation and decide whether the commercial price should increase.
